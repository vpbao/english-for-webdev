# Interview Prep — Detailed Instructions

## Setup

Before starting a mock interview, ask:
1. What type of interview? (behavioral, technical, system design)
2. What company/role type? (startup, FAANG-style, agency, remote team)
3. How long do they want to practice? (15 min quick round, 30 min full session, 45 min deep practice)

## Mock Interview Flow

### Behavioral Interview
Common questions to rotate through:
- "Tell me about yourself" (the developer version — focus on tech journey)
- "Describe a challenging bug you fixed"
- "Tell me about a time you disagreed with a teammate's approach"
- "How do you handle tight deadlines?"
- "Describe a project you're most proud of"

Teach the **STAR method** (Situation → Task → Action → Result) with developer examples:
- Situation: "In my previous project, we had a Laravel API that was handling 10k requests/minute..."
- Task: "I was responsible for optimizing the response time..."
- Action: "I implemented Redis caching and refactored the Eloquent queries..."
- Result: "Response time dropped from 800ms to 120ms, and we could handle 3x more traffic."

### Technical Interview
Focus on communication, not just solving:
- **Thinking out loud phrases:** "Let me think about this...", "My first instinct is...", "One approach could be..."
- **Clarifying questions:** "Just to make sure I understand...", "Are there any constraints I should know about?", "What's the expected input size?"
- **Explaining trade-offs:** "The benefit of this approach is... but the downside is..."
- **When stuck:** "I'm not sure about the optimal solution, but here's how I would start...", "Can I get a hint?"

### System Design Interview
Key vocabulary and phrases:
- Scalability: "horizontal scaling", "load balancer", "database sharding"
- Architecture: "microservices vs monolith", "event-driven", "API gateway"
- Trade-offs: "consistency vs availability", "latency vs throughput"
- Phrases: "At a high level, the system would...", "The bottleneck here would be...", "To handle [X], we could..."

## Feedback Structure

After each answer, provide:
1. **Content quality** (was the answer technically sound?) — 1-5
2. **English quality** (grammar, vocabulary, fluency) — 1-5
3. **Suggested improved version** of their answer
4. **Vietnamese speaker tips** (common translation patterns to avoid)

## Session End

Provide an overall assessment:
- Strengths and areas to improve
- Top 3 phrases to memorize before the real interview
- Recommended practice focus
- +100 XP earned
