## Category 3: Communication Phrases

### Status Updates
- "I'm currently working on..." → Mình đang làm...
- "I've completed..." → Mình đã hoàn thành...
- "I'm blocked by..." → Mình bị chặn bởi...
- "I'll finish this by EOD" → Mình sẽ xong trước cuối ngày
- "It's in code review" → Đang chờ review code

### Asking for Help
- "Could you take a look at...?" → Bạn xem giúp... được không?
- "I'm not sure about the approach for..." → Mình không chắc về cách tiếp cận cho...
- "Do you have a moment to pair on this?" → Bạn có rảnh để pair programming không?

### Code Review
- "Consider using... instead" → Nên cân nhắc dùng... thay vì
- "This might cause... because..." → Cái này có thể gây ra... vì...
- "Nice refactor!" → Refactor đẹp!
- "Nit: ..." → Góp ý nhỏ: ... (không bắt buộc sửa)
- "LGTM" → Looks Good To Me (OK rồi)

### Disagreeing Politely
- "I see your point, but..." → Mình hiểu ý bạn, nhưng...
- "Have we considered...?" → Mình đã cân nhắc... chưa?
- "What if we..." → Nếu mình... thì sao?

### Meetings
- "To summarize..." → Tóm lại...
- "My concern is..." → Mình lo ngại về...
- "Let me share my screen and walk you through..." → Để mình share màn hình và giải thích...

## Category 4: Error & Bug Description

- "The app crashes when..." → App bị crash khi...
- "I can reproduce this by..." → Mình có thể tái tạo lỗi bằng cách...
- "Expected behavior: ... / Actual behavior: ..." → Kỳ vọng: ... / Thực tế: ...
- "This only happens in..." → Lỗi này chỉ xảy ra ở...
- "The root cause seems to be..." → Nguyên nhân gốc có vẻ là...
- "Stack trace shows..." → Stack trace cho thấy...

## Category 5: Documentation

- "This module is responsible for..." → Module này chịu trách nhiệm...
- "Parameters: ... Returns: ..." → Tham số: ... Trả về: ...
- "Usage example:" → Ví dụ sử dụng:
- "Note: this is deprecated since v2.0" → Lưu ý: đã ngừng hỗ trợ từ v2.0
- "See also: ..." → Xem thêm: ...

## Important Collocations

These word pairs go together naturally — memorize them as units:
- deploy **TO** production
- merge **INTO** main/develop
- depend **ON** a library
- result **IN** an error
- consist **OF** multiple services
- responsible **FOR** the feature
- familiar **WITH** the codebase
- compatible **WITH** Node 18
- migrate **FROM** v2 **TO** v3
- refactor **INTO** smaller functions
